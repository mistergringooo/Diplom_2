# Diplom_2 — API-тесты Stellar Burgers

Автоматизированные API-тесты для сервиса заказа бургеров Stellar Burgers (`https://stellarburgers.education-services.ru/api`). Дипломный проект курса «Тестировщик ПО с нуля» (Яндекс Практикум).

## Что проверяется

- **Регистрация пользователя** — успешная регистрация, попытка зарегистрировать существующего пользователя, регистрация без обязательного поля
- **Авторизация** — вход с корректными данными, вход с неверным логином/паролем
- **Создание заказа** — с авторизацией и без, с ингредиентами и без, с некорректным хешем ингредиента

**9 тестов**, объединены в классы `TestRegister`, `TestLogin`, `TestOrders` (по одному классу на эндпоинт).

## Стек

Python, pytest, requests, Allure

## Структура проекта

```
├── api_client.py     # класс StellarBurgersAPI: register_user, login_user, delete_user, get_ingredients, create_order
├── data.py           # базовый URL, константы текстов ошибок
├── helpers.py        # генерация тестовых пользователей
├── conftest.py       # фикстура registered_user (регистрация + автоочистка после теста)
├── test_register.py
├── test_login.py
└── test_orders.py
```

## Как запустить

```bash
pip install -r requirements.txt
pytest --alluredir=allure-results
allure serve allure-results
```

## Находки

Подтверждено, что сервер разрешает создание заказа без авторизации (возвращает 200) — поведение соответствует документации, но отдельно протестировано и зафиксировано тестами `test_orders.py`.

## Планы по доработке

- Добавить тесты на получение списка заказов авторизованного пользователя
- Вынести конфигурацию окружения (base URL) в `.env`
